# Server Badge

Run `bb server-badge` to print which bb server you are on: the public app
hostname (or `user@host:port` when the server has no app URL), then the box's
hostname, the server's Unix user, its loopback port, and its app URL.

The same name is shown in bb's UI as a small badge in the bottom-right corner;
hover it for the details.
