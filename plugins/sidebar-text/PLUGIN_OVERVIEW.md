Pin a short note, reminder, or greeting to its own page in the bb sidebar.

## What you get

- A **Sidebar text** page in the left sidebar that shows your message.
- A **Message** setting you edit in Settings or with
  `bb plugin config sidebar-text set message "..."`; the page updates live.

## How it works

The message is stored as a plugin setting on the bb server. The plugin makes
no network requests and needs no account.
